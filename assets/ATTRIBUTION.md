# Assets & Credits

Local visual assets in this profile README were assembled for a neon / terminal look.

## Generated in-repo
- `assets/banner.png` — cyber HUD header
- `assets/terminal.png` / `assets/terminal.svg` — boot-sequence terminal
- `assets/skills.svg` — tech-stack wall
- `assets/divider.svg` / `assets/footer.svg` — neon HUD lines
- `dist/github-snake.svg` — contribution snake output (generated by GitHub Action)
